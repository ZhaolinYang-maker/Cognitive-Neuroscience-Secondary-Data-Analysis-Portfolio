# Sleep Deprivation and Cognitive Performance

This repository contains my first independently designed secondary-data
analysis project. The project uses a theory-guided and exploratory approach
to investigate relationships among sleep-related measurements, emotional
regulation, psychological states, and cognitive-task performance.

## Current Status

- Project overview and analysis plan completed
- Data screening and preparation in progress
- Research Aim 1 analysis will be conducted first

## Research Aims

### Aim 1: Sleep-Related Measurements and Emotional Regulation

This aim examines whether sleep duration and sleep quality are associated
with emotional-regulation performance. It also examines whether sleep
quality moderates the relationship between sleep duration and emotional
regulation.

### Aim 2: Psychological States and Cognitive-Task Performance

This aim examines relationships between psychological or sleep-related
measurements and performance on the Stroop task, N-back task, and
Psychomotor Vigilance Task.

An exploratory PCA will first examine whether the three cognitive-task
measurements can be compressed into a coherent overall
cognitive-performance index. If no sufficiently dominant and interpretable
principal component is identified, the three outcomes will be analyzed
separately.

## Project Positioning

This project is an exploratory and theory-guided secondary-data analysis.
The observational design does not support causal conclusions.
